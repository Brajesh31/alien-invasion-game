# 🆘 Support

## Before Asking for Help

1. Read the [README](README.md).
2. Follow the [Installation Guide](docs/installation.md).
3. Check [Troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md).
4. Search existing repository issues for a similar problem.

## Information to Include

A useful support report should contain:
- Operating system and version.
- Python version.
- Pygame version.
- Exact command used to start the game.
- Working directory from which it was launched.
- Reproduction steps.
- Expected and actual behavior.
- Sanitized terminal traceback.
- Whether a graphical display and audio device are available.

For gameplay bugs, identify the affected control or mechanic, such as ship movement, bullet firing, UFO movement, collision, scoring, game over, or exit behavior.

## Where to Ask

Use GitHub Issues for reproducible bugs, feature requests, and documentation improvements. Choose the appropriate issue template and provide enough context to reproduce the problem.

## Privacy and Security

Do not include private files, personal information, access tokens, passwords, or unrelated system details. Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities rather than publishing exploit information in a public support issue.

## Project Scope

This repository supports a local Python/Pygame game. It does not provide online accounts, network gameplay, a cloud leaderboard, or database support. Requests involving those systems require new, separately scoped functionality.
